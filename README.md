# CPU Boost (beta)

Optimizador de CPU y GPU para Linux. Funciona con procesadores Intel y AMD Ryzen, y con GPU Intel, AMD y NVIDIA. Incluye Game Boost.

CPU and GPU optimizer for Linux. Works with Intel and AMD Ryzen processors and Intel, AMD and NVIDIA GPUs. Includes Game Boost.

## Instalar / Install

```
mkdir -p ~/.local/bin
cp cpu_optimizer.py ~/.local/bin/cpu-optimizer
chmod +x ~/.local/bin/cpu-optimizer
python3 ~/.local/bin/cpu-optimizer
```

Requiere Python 3, Tk y polkit.
